# Contributing

Contributions are welcome! Please follow these steps:

## Reporting Issues

Use the [issue tracker](https://github.com/nadimtuhin/chrome-react-boilerplate/issues) to report bugs or request features. Include:

- Chrome version
- Node.js version
- Steps to reproduce
- Expected vs actual behaviour

## Pull Requests

1. Fork the repo and create your branch from `master`
2. Run `npm install` to set up dependencies
3. Make your changes; run `npm run lint` to check for style issues
4. Open a pull request with a clear description of the change

## Code Style

This project uses ESLint. Run `npm run lint` before submitting.
